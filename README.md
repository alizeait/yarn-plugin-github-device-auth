# yarn-plugin-github-device-auth

Automatically authenticate GitHub packages in Yarn with GitHub Device Flow 

## Installation

```bash
pnpm add yarn-plugin-github-device-auth
```

Or using other package managers:

```bash
npm install yarn-plugin-github-device-auth
# or
yarn add yarn-plugin-github-device-auth
# or
bun add yarn-plugin-github-device-auth
```

## Usage

```typescript
import { example } from 'yarn-plugin-github-device-auth';

example();
```

## Development

```bash
# Install dependencies
pnpm install

# Run tests
pnpm test

# Build
pnpm build

# Check types
pnpm check-types

# Lint
pnpm lint

# Format
pnpm format
```
